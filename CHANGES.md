# CHANGES — local-models edition

What changed relative to the upstream fork (`poldrack/ai-peer-review`):
the cloud LLM API clients were removed and replaced with a single
`LocalLLMClient` that talks to any OpenAI-compatible local inference server
you run yourself. No third-party LLM API is contacted anywhere in the code.

## Why

The upstream tool submitted the manuscript to OpenAI, Anthropic, Google, and
Together.ai. For peer review of **unpublished** manuscripts intended for Q1
SCI journals, sending the text to a third-party LLM API is unacceptable: the
provider may log or retain the prompt. This fork makes the tool structurally
incapable of that — there is no longer any code path that sends the manuscript
to a cloud LLM provider.

## File-by-file

### Removed (cloud API clients + their tests)
- `src/ai_peer_review/llm_clients/openai_client.py` — OpenAI cloud client.
- `src/ai_peer_review/llm_clients/anthropic_client.py` — Anthropic cloud client.
- `src/ai_peer_review/llm_clients/google_client.py` — Google Gemini cloud client.
- `src/ai_peer_review/llm_clients/deepseek_client.py` — DeepSeek via Together.ai.
- `src/ai_peer_review/llm_clients/llama_client.py` — Llama 4 via Together.ai.
- `tests/llm_clients/test_openai_client.py`
- `tests/llm_clients/test_anthropic_client.py`

### Added
- `src/ai_peer_review/llm_clients/local_client.py` — `LocalLLMClient`, the
  only LLM client. Uses the `openai` Python SDK pointed at a configurable
  `base_url` (default Ollama `http://localhost:11434/v1`). No real API key
  required (placeholder `"local"` is sent; local servers ignore it). Works
  with Ollama, LM Studio, llama.cpp `llama-server`, vLLM, LocalAI, TGI.
- `tests/llm_clients/test_local_client.py` — unit tests for the local client
  (init precedence: args > env > config > default; generate payload shape).

### Modified
- `src/ai_peer_review/utils/config.py`
  - `get_default_config()` now ships `local_server`, `local_models`
    (one default reviewer `reviewer-1` → `qwen3:32b`), and `meta_reviewer`
    sections, alongside the original `api_keys` and `prompts`.
  - New helpers: `get_local_server_config`, `set_local_server`,
    `get_local_models`, `set_local_model`, `remove_local_model`,
    `get_meta_reviewer_config`, `set_meta_reviewer`.
  - `get_api_key` / `set_api_key` retained (harmless, backward compatible) but
    unused by the local pipeline.

- `src/ai_peer_review/review.py`
  - Replaced cloud-client imports with `LocalLLMClient`.
  - New `_build_local_client(cfg, config_file)` builds a `LocalLLMClient` from
    a config entry, inheriting `local_server` defaults for `base_url`/`api_key`.
  - `get_client_factories(config_file)` builds the `{name: factory}` mapping
    from `local_models`; each factory is instantiated on demand only.
  - `get_meta_reviewer_client(config_file)` builds the meta-reviewer client
    from the `meta_reviewer` section (replaces the hardcoded Google Gemini).
  - `process_paper` and `generate_meta_review` signatures unchanged; they now
    drive everything from config.
  - Removed unused `import os`, `import random`.

- `src/ai_peer_review/cli.py`
  - `config` is now a **group** with subcommands: `show`, `server`, `add`,
    `remove`, `meta` (replaces the old `config <service> <api_key>` command).
  - `get_available_models(config_file)` is now dynamic — reads the keys of
    `local_models`.
  - `list-models` lists configured reviewer names.
  - `review` command: replaced the second hardcoded `GoogleClient`
    (concerns-extraction JSON call) with `get_meta_reviewer_client(config_file)`.
  - Removed dead `from .review import save_concerns_as_csv` import.
  - Help text updated throughout to reflect local-only operation.

- `pyproject.toml`
  - `requires-python` relaxed `>=3.13` → `>=3.10`.
  - Removed deps no longer imported: `anthropic`, `google-generativeai`,
    `pydantic`, `requests`, `tiktoken`, `tqdm`, `structlog`, `ipykernel`.
  - Kept: `click`, `pypdf`, `openai>=1.0`, `python-dotenv`, `pandas`,
    `pytest>=8.3.5`.
  - `uv.lock` deleted (will be regenerated by `uv sync` / `uv lock`).

- `.env.example` — replaced cloud API-key entries with
  `AI_PEER_REVIEW_BASE_URL` and `AI_PEER_REVIEW_API_KEY` (local server).

- `configs/scientific-only.json` — prompts unchanged; added
  `local_server`, `local_models` (two reviewers: `qwen3:32b` +
  `deepseek-r1:70b`), and `meta_reviewer` so the profile works locally
  out of the box.

- `README.md` — rewritten for local-model usage: confidentiality rationale,
  recommended open-weight models (Kimi K3, DeepSeek-R1/V3, Qwen3, Llama 4
  Scout, Llama 3.3, GLM-5.1, Gemma 3) with context lengths and rough VRAM,
  hardware sizing guidance, quick start, multi-reviewer setup, config
  reference, troubleshooting, and how to apply the changes to your fork.

- `tests/test_review.py` — rewritten `test_process_paper` and
  `test_generate_meta_review` to mock `get_client_factories` /
  `get_meta_reviewer_client` (no cloud clients to patch). Added
  `test_process_paper_filters_unknown_models`.

- `tests/test_cli.py` — rewritten for the new `config` subcommands
  (`test_config_add`, `test_config_server`, `test_config_meta`,
  `test_config_remove`, `test_config_show`, `test_list_models`) and the
  config-driven `review` command. Patches target the `cli` namespace
  (`ai_peer_review.cli.process_paper`, etc.) because `cli.py` imports those
  names directly.

- `tests/test_config.py` — added assertions in `test_get_default_config` for
  the new `local_server`, `local_models`, `meta_reviewer` sections.

### Unchanged
- `src/ai_peer_review/llm_clients/base_client.py` (abstract `BaseLLMClient`).
- `src/ai_peer_review/utils/pdf.py` (`extract_text_from_pdf`).
- `src/ai_peer_review/version.py`, `__init__.py` files, `LICENSE`,
  `tests/test_pdf.py`, `tests/llm_clients/test_base_client.py`.
